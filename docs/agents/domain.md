# Domain docs

This repository uses a single context:

- Read root GLOSSARY.md before exploring, when it exists.
- Read relevant decisions in docs/adr/, when present.
- Proceed silently when these documents are absent; create them
  through domain-modeling as terms and decisions are resolved.
- Use glossary terms consistently.
- Explicitly flag proposals that conflict with an existing ADR.

Read HANDOFF.md and docs/requirements.md for project context.
Before designing or implementing instance resource allocation,
read docs/handoff-instance-isolation.md. Its source findings
still require runtime verification.
