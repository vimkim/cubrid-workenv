# my-cubrid-runtime

호스트에서 CUBRID worktree별 DB와 실행 설정을 명시적으로 초기화하는 도구.

프로젝트 홈: `/home/vimkim/gh/my-cubrid-runtime`

[요구사항](docs/requirements.md)에 목적, 초기화 범위, 수용한 위험과 구현 확인 기준을 기록했다. 현재는 요구사항을 정리한 단계이며 CLI 구현은 포함하지 않는다.

컨테이너 실행 도구의 프로젝트 홈은 `/home/vimkim/gh/my-cubrid-container`이다. 컨테이너 내부에서는 `my-cubrid-runtime` 초기화를 요구하지 않는다.

새 주 에이전트는 [인계 문서](HANDOFF.md)부터 읽는다.
